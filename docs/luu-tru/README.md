# Lưu trữ

Tài liệu không còn dùng hằng ngày. **Giữ nguyên văn để tham khảo**, không sửa cho khớp hiện tại. Khi một tài liệu ở đây mâu thuẫn với `docs/` đang dùng hoặc `docs/01`, tài liệu đang dùng thắng.

Tệp chuyển vào đây giữ **cùng tên**: quyết định hay task cũ nhắc `docs/24`, `docs/29`… thì tìm `docs/luu-tru/24-…`, `docs/luu-tru/29-…`.
